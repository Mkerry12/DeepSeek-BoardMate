# DeepSeek DeskMate 产品设计文档

> 版本：对应客户端 v0.2.x / 后端当前 main。本文描述**已经实现**的产品形态（以代码为准），最后一节是规划。
> 架构与接口细节见 [架构文档](架构文档.md)。

## 1. 产品定位

DeepSeek DeskMate 是一只住在 Windows 桌面上的 **Live2D AI 桌宠**：角色是「DS鲸鱼娘」小鲸，会聊天、有表情和动作、
会朗读、记得你说过的事，也会在你闲着、忙着、该喝水的时候主动做点什么。

和一般的 AI 聊天窗口相比，它的重点是**陪伴感和低打扰**：

- 透明置顶的小窗口，鼠标没指着她时完全穿透，不挡工作；
- 回复短（默认要求 80 字以内）、带情绪标签驱动表情动作，像在跟一个角色说话而不是查资料；
- 大模型可以跑在**主人自己的电脑上**（Ollama + DeepSeek-R1 蒸馏模型），朋友装一个 exe、填一个令牌就能用，不需要任何 API 费用；
- 也可以填自己的 DeepSeek / OpenAI 兼容 API Key 单机使用。

## 2. 目标用户

| 用户 | 场景 | 关心什么 |
| --- | --- | --- |
| **主人**（部署者） | 自己电脑上有显卡，跑 Ollama + 后端，经内网穿透分享给朋友 | 部署简单、令牌好管理、不被滥用、显存够用 |
| **主人的朋友** | 只装客户端（安装版自动更新），连主人的服务器 | 装上就能用、不用配置、免费 |
| **自建用户**（拉取 GitHub 代码的人） | 想在自己电脑上跑一套 | 一键部署、文档清楚、能换模型 / 音色 |
| **API Key 用户** | 没有显卡，有 DeepSeek 等平台的 Key | 不经过别人的服务器、Key 安全保存 |
| **贡献者** | 改角色、加功能 | 代码结构清晰、有测试、CI 把关 |

## 3. 典型使用场景

1. **陪伴工作**：小鲸待在屏幕角落；长时间不理她会自拍、吹泡泡、吃巴菲，5 分钟没动静就打瞌睡；碰一下就醒。
2. **随手问一句**：双击她（或点桌上的画笔）弹出输入框，问完她边想边拿笔在小本本上记，回答一句句冒出来、一句句读出来。
3. **解释剪贴板**：复制一段看不懂的文字，右键「看看剪贴板」，她来解释。
4. **专注**：右键「番茄钟」，25 分钟专注 + 5 分钟休息；喝水、久坐提醒按设置的间隔弹出。
5. **互动解闷**：摸头、戳脸、点头顶的小鲸鱼喷水、连戳会生气抡锤子；抽今日运势；换眼镜、发饰、桌布。
6. **分享给朋友**：主人跑一键部署脚本，用 `tokens add 小明` 给每个朋友发令牌，朋友装安装版、填令牌即用，以后自动更新。

## 4. 功能清单（按模块）

### 4.1 角色与 Live2D

- 模型：DS鲸鱼娘（Cubism 3/4/5 模型，pixi.js + Live2D 引擎渲染），角色数据都在角色目录的 `deskmate.json`：
  台词、触摸区域、闲置活动、换装、运势、问候、提醒文案、情绪映射。换角色 = 换一个目录。
- **情绪 → 表情 / 动作**：模型每次回复开头输出一个情绪标签（`happy sad angry surprised relaxed thinking wave neutral shy love cry confused dizzy speechless proud sleepy`），
  客户端按 `live2d.emotions` 叠加表情层、播放动作。标签的唯一来源是 `shared/emotion-tags.json`，客户端和服务器都读它。
- **状态表现**：思考时拿笔写字、回复超过 150 字把头顶的小鲸鱼放到桌上、失败或没话说会吐魂。
- **口型**：朗读时按实际音量驱动嘴型（WebAudio 分析器）；不朗读时按文字输出节奏做正弦口型。

### 4.2 聊天与情绪

- 两种连接方式输出同一套事件（`thinking / queued / emotion / delta / error / done`），界面不区分来源：
  - **官方服务器**：连主人的后端（Ollama），只需令牌；可选服务器上的模型（自动排除 bge-m3 等嵌入模型），可自定义人设；
  - **自己的 API Key**：客户端直连 OpenAI 兼容接口，预设 DeepSeek 官方（`deepseek-chat` / `deepseek-reasoner`），也可自定义地址和模型。
- 流式显示；`<think>` 思考过程被过滤（服务端和客户端各有一份流式过滤器），只显示「在想…」。
- 服务器忙时显示「排队中」；随时可停止（Esc / 按钮 / 发新消息）。
- 自定义人设只替换人设部分，情绪标签规则始终保留。

### 4.3 触摸互动

- 单击头 = 摸头（爱心眼 + 心跳）；按住在头上小范围来回蹭也算摸头（拖出约 36 px 才变成拖窗口）。
- 戳脸脸红；点头顶（或桌上）的小鲸鱼喷水；3 秒内连戳 5 下先晕再抡锤子；拖着窗口左右猛晃会晕。
- 其他部位单击是随机台词反应，双击打开聊天输入框。

### 4.4 闲置行为与问候

- 一段时间没互动：随机小动作（自拍、吹泡泡、挤番茄酱、吃巴菲……，来自角色配置），偶尔配一句台词；5 分钟无动静打瞌睡，任何互动叫醒。
- 按时段打招呼：早上 8–10 点、午饭 11:45–13 点、晚饭 17:45–19:30、深夜 23:30–5 点，每天每个时段一次；正在聊天时先不打扰。
- 启动欢迎语；右键「打招呼」挥手。

### 4.5 桌上道具

纸上的三个图标可以点：**撤回**（删掉上一轮对话）、**画笔**（打开输入框）、**橡皮**（连点两下清空对话）。
思考时画笔亮、回复完橡皮亮、按停止时撤回亮。

### 4.6 记忆

- **聊天记录**：`history.json` 最多 200 条，每次只把最近 20 条发给模型；右键「清空记忆」只擦聊天记录。
- **长期记忆（她记得的事）**：每新聊 40 条，后台让模型把关于你的事（称呼、喜好、在忙的事、约定）整理成 ≤ 500 字的笔记（`memory.json`），
  之后每次聊天附在系统提示词后面。右键「她记得的事」→ 查看 / 现在整理一下 / 忘掉这些。和聊天记录互不影响。

### 4.7 小助手

- 喝水提醒（默认 45 分钟）、久坐提醒（默认 60 分钟），设置里开关和改间隔；忙的时候稍后再提醒。
- 番茄钟：25 分钟专注 + 5 分钟休息。
- 看看剪贴板：读取剪贴板文字（最多 900 字）让她解释。

### 4.8 换装、运势

- 换装：眼镜、贴纸、发饰、手势、魔爪、桌布等槽位，同一槽位互斥，重启后保留；槽位和默认装扮由角色配置决定。
- 今日运势：按日期做种子，同一天结果固定；掏出手机翻开看一眼再念给你听。

### 4.9 语音

- **朗读回复**（默认关）：右键「语音朗读」或设置里开关；边输出边按句切分、依次合成、按顺序播放；按停止 / Esc / 发新消息 / 关开关立刻停。
- **合成来源**（按优先级）：
  1. 官方模式：服务器 `POST /tts`。服务器可配置为
     - **Edge**（默认）：微软 Edge 神经网络语音，6 个中文音色可选；
     - **GPT-SoVITS**：主人电脑上的本地模型，自定义音色（由参考音频决定），离线、占用显卡；不可用时自动改用 Edge。
       设置里的音色下拉框会显示服务器上配置的音色。详见 [gpt-sovits.md](gpt-sovits.md)。
  2. API Key 模式，或服务器朗读失败：客户端主进程直连 Edge 语音；
  3. 都失败：Windows 自带语音（speechSynthesis）。
- 提示音（完成、失败、提醒）和朗读共用一个音量滑块（默认 80%），拖动时正在读的语音立刻跟着变。

### 4.10 设置与连接方式

右键「设置」：连接方式（官方服务器 / 自己的 API Key）、令牌、服务器地址（高级）、模型、人设、API 预设和 Key、
朗读开关 / 音色 / 提示音 / 音量、喝水和久坐提醒、自动更新。「测试连接」会逐项显示：服务器、Ollama 和模型、令牌、
（服务器用 GPT-SoVITS 时）GPT-SoVITS 是否在线；API Key 模式显示接口、Key、模型是否可用。

### 4.11 托盘、自启与更新

- 托盘图标：显示 / 隐藏、开机自启、检查更新、退出；右键菜单里还有总在最前、隐藏、重新加载。
- **安装版**自动更新：启动 15 秒后和每 6 小时检查，后台下载，提示「重启就能用上」；不点的话下次退出时自动安装。
- **便携版**不能自动更新：只提醒有新版本并打开下载页。

## 5. 交互细节

| 交互 | 行为 |
| --- | --- |
| 鼠标穿透 | 窗口透明、无边框、置顶（280×430）。指针不在角色 / 气泡 / 输入框 / 菜单上时，点击穿透到桌面 |
| 拖动 | 左键按住拖动窗口（按屏幕坐标计算，高 DPI 不漂）；在头上要拖出 36 px 才开始拖，避免和摸头冲突；窗口位置会记住 |
| 单击 / 双击 | 单击按触摸区反应，双击打开输入框 |
| 右键菜单 | 分组：聊天、剪贴板、番茄钟、运势、换装、打招呼 ｜ 设置、语音朗读、她记得的事、清空记忆、窗口 ｜ 更新、退出 |
| 对话气泡 | 在角色头顶，跟随模型高度；思考时显示打字动画；长回复自动滚到最新内容 |
| Esc | 先关菜单；没有菜单就收起输入框、关设置、停止朗读 |
| 失败提示 | 401 时提示去设置里填令牌 / Key；Ollama 未运行、余额不足等错误直接说人话 |

## 6. 非功能需求

| 方面 | 要求 / 现状 |
| --- | --- |
| **隐私** | 聊天记录、记忆、设置只存在用户电脑（`%APPDATA%\deepseek-deskmate\`）；官方模式下对话经过主人的服务器但服务器**不落盘**对话内容，日志只记请求路径、状态、耗时和令牌标签。API Key 用 Windows DPAPI 加密保存 |
| **延迟** | 首字取决于模型（8B 本地模型通常 1~3 秒）；朗读第一句 Edge 约 1 秒、GPT-SoVITS 约 1.5~2.5 秒（刚启动 10~30 秒，有预热） |
| **资源占用** | 客户端是单个 Electron 小窗口（Live2D 持续渲染，有一定 GPU 占用，可用托盘隐藏）；服务器端 8B 模型约 5~6 GB 显存，GPT-SoVITS 约 2.7 GB，二者可共存于 8 GB 卡但同时生成会变慢 |
| **并发** | 聊天并发 `MAX_CONCURRENCY`（默认 2），超出排队；Edge 朗读最多 4 路并发；GPT-SoVITS 单卡串行、最多排 8 句 |
| **安全** | 令牌只存 sha256；按令牌限流（聊天 20 次/分、朗读 90 句/分）；可随时撤销；只映射后端端口，不暴露 Ollama / GPT-SoVITS；容器以非 root 运行；CI 有 gitleaks 密钥扫描 |
| **可用性** | GPT-SoVITS 挂了自动退回 Edge，Edge 挂了退回客户端直连，再不行用系统语音；旧客户端连新服务器、新客户端连旧服务器都能用 |
| **可维护性** | TypeScript strict + ESLint + Prettier；后端 ruff + pytest；IPC 契约类型化；PR 必须 CI 全绿 + 1 人 review |
